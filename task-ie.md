### Проект

* Android приложения для локального хранения заметок. 
* Написано изначально на Java.
* Все новые классы создавать на Kotlin.

### Цель

* Реализовать возможность импорта и экспорта локальных заметок через сериализацию и запись в json файл. 

### Реализация

* В SettingsActivity реализовать 2 кнопки - Импорт и Экспорт. Локализация ресурсов ru и eng. Стиль - плитка. Цветовая схема консистентна с остальными кнопками приложения. 
* Кнопка Импорт должна открывать пикер файла, после выбора файл должен парситься и результаты должны заноситься в базу данных Room, она локальна в приложении. 
* Кнопка Экспорт должна реализовать функционал экспорта данных из базы данных в файл.
* После завершения импорта или экспорта экран должен возвращаться на SettingsActivity

### Задача для агента.

##### Первый агент
* Предложить реализацию.
* Реализовать функционал в текущей ветке.
* После тестирования внести правки. 

##### Второй агент

* Покрыть новый функционал автотестами.
* Протестировать на подключенном по adb телефоне новый функционал. 
* Составить отчет о тестировании, передать его агенту 1.
